# Code of Conduct

Jervis should be a welcoming project for people who want to build, learn, test, document, or improve it.

## Expected behavior

- Be respectful and constructive.
- Critique ideas and code, not people.
- Give useful context when reporting bugs.
- Assume good faith while still being precise about technical problems.
- Respect privacy. Do not publish another person's credentials, recordings, biometric data, or private messages.

## Unacceptable behavior

Harassment, threats, targeted abuse, discriminatory conduct, doxxing, or deliberate publication of private data are not acceptable.

## Enforcement

Project maintainers may edit, hide, or remove content and restrict participation when necessary to keep the project safe and productive.

If you need to report a sensitive security matter, follow [SECURITY.md](SECURITY.md).
