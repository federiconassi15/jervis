# Jervis 8.2 Computer Awareness — resource metrics foundation

Opt-in read-only resource sampling using installed psutil. CPU, RAM, disk
capacity and battery charge are summarized; no process names, window titles,
paths, networks, screenshots or user documents are captured. No daemon,
polling or persistent collection is started by default. The metrics are
transient data. Any remote access requires explicit authorization and a
separate connected companion protocol.

This is not the full 8.2 Computer Awareness feature: application awareness,
OS notifications, service health events and platform-specific capture grants
require dedicated adapters, tests and user-facing permission controls.
