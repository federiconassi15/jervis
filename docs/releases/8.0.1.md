# Jervis 8.0.1 — POSIX Bootstrap Hardening

Jervis 8.0.1 is a maintenance release on the 8.0 line. It contains the two installer fixes made after 8.0.0, without introducing the draft 8.1 features.

## Added

- None.

## Changed

- None to the interactive setup flow, runtime configuration or public CLI.

## Removed

- None.

## Fixed

- On Linux and macOS, the bootstrap creates an unpredictable, private temporary directory for the native installer, checksum and download logs, preventing predictable-directory precreation and symlink attacks in shared temporary locations.
- The POSIX bootstrap waits for the native installer to exit, preserves its exit status, and deletes temporary native payloads and checksums on success or failure.

## Compatibility and validation

- Remains on the 8.0 major/minor line, with the existing configuration and state formats.
- Does not change dependency pins, Windows bootstrap, service configuration, audio engines or OpenClaw integration.
- Native targets remain Linux x64/ARM64, Windows x64 and macOS Intel/Apple Silicon.
- Focused private-directory and cleanup regression tests passed for the fixes. Pre-release CI on the latest fix passed all 12 jobs ([CI run](https://github.com/federiconassi15/jervis/actions/runs/40071072770)).
- The release workflow separately builds and verifies distributable artifacts before publishing; a passing CI run alone is not a release.

See the [Jervis 8.0.0 notes](8.0.0.md) for the major plain-terminal-interface changes.
