# Jervis 7.3.6

Jervis 7.3.6 is an installer-polish release for the 7.3 line. It keeps the 7.3.5 recovery model intact while making fresh installs substantially quieter and the Installation Control Deck resilient to live terminal resizing.

## Added

- Responsive installer layout modes for normal, compact, and tiny terminal sizes.
- Live terminal-resize handling that automatically reflows the Control Deck without restarting setup.
- Regression coverage that resizes the installer across wide, compact, tiny, and wide-again terminal dimensions.
- Quiet Linux dependency execution that preserves visible sudo authentication while capturing package-manager output.
- Concise package-manager failure tails so errors remain actionable without dumping full apt/dpkg/dnf/pacman/zypper/apk logs into the installer.

## Changed

- Linux/macOS bootstrap downloads now use silent curl/wget operation with Jervis-owned status messages.
- Windows bootstrap disables PowerShell transfer progress and uses the same concise Jervis-owned download/verification messaging.
- Linux prerequisite installation uses quiet package-manager flags and noninteractive package frontends after sudo authentication.
- The Control Deck frame now consumes available terminal width safely instead of depending on a mostly fixed desktop-sized canvas.
- Installer pages remain vertically scrollable as terminal height shrinks.
- Navigation buttons use smaller responsive minimum widths and hide secondary hints when space is constrained.
- Wide decorative section headings are now width-independent labels so narrow SSH terminals do not clip box-drawing characters.
- The animated Jervis hero collapses to a one-line header in compact mode and is removed entirely in tiny mode.
- The step bar collapses progressively from the full subsystem rail to compact labels and finally a single current-step indicator.

## Removed

- Curl transfer meters from the public POSIX bootstrap.
- Successful apt/dpkg/dnf/pacman/zypper/apk transaction output from normal installer presentation.
- Reliance on fixed-width decorative headings for core setup navigation.

## Fixed

- Resizing an SSH/terminal window during installation no longer leaves the Control Deck dependent on stale desktop-scale dimensions.
- Small terminal windows no longer sacrifice the page viewport to decorative header elements.
- Bottom navigation remains reachable as terminal dimensions change.
- Successful Linux prerequisite installation no longer floods the terminal before or behind the Textual installer UI.
- Package-manager errors remain visible in a bounded form instead of being either completely hidden or overwhelmingly verbose.

## Compatibility

- Jervis 7.3.6 remains on the 7.3 maintenance line and does not change the runtime/state compatibility boundary introduced by 7.3.5.
- Official native targets remain Linux x64/ARM64, Windows x64, macOS Intel, and macOS Apple Silicon.
- Sudo authentication remains interactive where required; only the package-manager transaction output is hidden on success.
- Terminals that are too small for the full visual shell automatically receive a reduced layout rather than being rejected.

## Code basis

This description is derived from the actual 7.3.6 quiet-bootstrap, quiet-prerequisite, and responsive-installer code changes over Jervis 7.3.5.
