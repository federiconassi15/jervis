# Jervis 8.0.0 — Simple by Default

Jervis 8 replaces the default fullscreen terminal experience with straightforward commands and numbered setup prompts. This release is intended to reduce terminal-rendering failures reported by users; it is not yet evidence that every reported UI bug is fixed.

## Added

- A lightweight home menu available through `jervis` or `jervis home`.
- Plain text status, repair, and update navigation without requiring a fullscreen renderer.
- A numbered setup flow with visible defaults, cancellation, masked local passphrase entry, audio-device selection, owner setup, and explicit confirmation before installation.
- Noninteractive help text rather than blocking on an unreadable or piped terminal.

## Changed

- `jervis install` and the `jervis-installer` entry point now call the plain setup flow.
- `jervis tui` is a compatibility alias for the plain menu; it no longer opens curses. `jervis legacy-tui` explicitly opens the old Control Deck for features not yet available in command form.
- Guided OpenClaw onboarding launches the upstream `openclaw onboard` flow separately instead of embedding its changing setup steps inside the installer.
- `jervis run`, `jervis doctor`, `jervis status`, repair, recovery, snapshots, backup, benchmarks, presence, and the underlying transactional installer remain available.
- Release workflow version validation recognizes 8.x and upgrades the two upload and one download artifact actions to their supported majors.

## Removed

- Dependence on mouse events, fullscreen redraws, responsive sidebar layouts, and special key navigation.
- Automatic launch of the legacy Textual installer and curses Control Deck from public CLI entry points.

The legacy UI modules and their dependencies remain in this initial 8.0 migration to avoid breaking existing interfaces and tests. The old deck is opt-in only.

## Fixed

- Terminals without full TUI capabilities no longer need to render the installer or Control Deck to access normal commands.
- Piped invocation without a TTY shows useful command hints instead of entering an interactive screen.
- Installer questions finish before the transaction starts; rejected review does not install anything.
- OpenClaw onboarding interruption does not incorrectly report that the Jervis core installation rolled back.

## Compatibility and known limitations

- Jervis's configuration and state schemas remain unchanged from 7.4; this is an interface migration, not a data format migration.
- The same Desktop/Server, Android ADB microphone, audio output, owner authentication, service startup, and snapshot-backed installation engine are reused.
- OpenClaw's own onboarding may still display interactive prompts or open a browser; Jervis does not reimplement upstream provider/plugin onboarding.
- Existing native platform matrix remains Linux x64/ARM64, Windows x64, and macOS Intel/ARM64.
- The advanced Control Deck panels have not all been rewritten as plain commands yet; `jervis legacy-tui` keeps them reachable on terminals that support curses.
- Releasing requires passing CI, native smoke tests, installation dogfooding, and the release trigger. The version and documentation changes alone do not publish a release.
