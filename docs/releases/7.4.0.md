# Jervis 7.4.0

Jervis 7.4 “Feels Alive” makes Jervis more continuous, presence-aware, proactive, inspectable, and controllable while rebuilding the terminal experience around a stable sidebar layout.

## Added

### Installer and terminal experience

- A rebuilt installer shell with a persistent left-hand setup sidebar and a dedicated right-hand content pane.
- First-class visible Desktop and Server deployment cards. Server mode is no longer hidden in a select/dropdown.
- First-class visible Guided OpenClaw and Configure Later choices.
- A narrow-terminal fallback that replaces the sidebar with a compact current-stage label.
- Resize coverage that keeps installation navigation reachable while moving between wide, compact, and narrow terminal sizes.
- A matching sidebar navigation model for the runtime Control Deck on normal terminal widths.

### Continuity and memory

- Memory provenance and importance metadata.
- Memory access metadata for relevance weighting and inspection.
- Query-aware memory selection using lexical relevance, explicit importance, recency, and prior access.
- Compact per-user rolling session summaries stored separately from full dialogue.
- Session/topic continuity injected into OpenClaw context without replaying entire transcripts.
- Correction-aware context for phrases such as “no, I meant…” and “actually, I meant…”.
- Control Deck memory editing and deletion controls.
- Snapshot-backed config/database migration into the 7.4 schemas.

### Presence

- Presence transition history for entered, left, and returned states.
- Active-speaker handoff tracking when the recognized user changes.
- A configurable-source presence API through `jervis presence`.
- External room/device integrations can mark a known user present or away with arbitrary source labels such as `room:office` or `phone:pixel`.
- Presence history inspection through the CLI and Control Deck.

### Proactive behavior

- Priority, expiry, not-before, retry metadata, and human-readable delivery reasons for queued notifications.
- User busy windows that suppress proactive interruption without deleting queued work.
- Local relative reminders such as “remind me in 20 minutes to …”.
- Persistent local condition watches.
- Built-in condition evaluation for OpenClaw becoming healthy, file existence, and internal state equality.
- Voice commands for real “tell me when OpenClaw is back” and file-exists watches.
- Condition watches become normal proactive notifications only after the condition evaluates true.
- Condition-watch expiry and cancellation.
- Explanations for the most recent proactive delivery.
- Control Deck views for queued notifications and active condition watches.

### Agent orchestration and permissions

- Normalized agent capability/tool metadata without assuming a single OpenClaw response schema.
- Per-user agent-run history with route, agent, status, start/end state, and failure detail.
- Real cancellation requests for active long-running deep agent runs.
- CLI-backed OpenClaw cancellation terminates the full process tree on Windows and the process group on POSIX.
- Action/tool timeline storage for action metadata OpenClaw actually returns.
- Control Deck views for available agent capabilities, recent runs, cancellation, and action metadata.
- Privileged skills may expose a cheap `can_handle(text, context)` matcher so Jervis can request permission without executing the privileged handler.
- Permission-escalation events are recorded when such a skill matches but the current user/auth context is insufficient.

### Control Deck

- Sidebar navigation on normal terminal widths.
- Compact panel navigation on narrow terminals.
- Live service/OpenClaw/acceleration/latency dashboard.
- Benchmark-history panel.
- Presence-aware people view with active-speaker marker.
- Memory + session-summary browser with explicit provenance and importance.
- Memory add/edit/delete actions.
- Proactive queue + condition-watch view and cancellation.
- Agent capability, run-history, cancellation, and action-timeline views.
- Existing recovery/snapshot/repair controls remain available.

## Changed

- The installer no longer uses an animated ASCII hero or a continuously repainting decorative shell.
- The 7.3 horizontal numbered setup rail is replaced by semantic sidebar stages.
- Installer pages are scrollable independently from navigation.
- Explicit voice memories are stored with provenance and elevated importance.
- OpenClaw context retrieval ranks memories against the current request rather than selecting only by write time.
- Recent session summaries are preferred for cross-session continuity instead of enabling full transcript replay by default.
- Presence-aware proactive delivery prefers the current active user.
- Proactive items remain queued when nobody relevant is present or the user is inside a busy window.
- Deep OpenClaw calls use a cancellable CLI execution path so a shared cancellation request can terminate the task safely.
- The fast HTTP OpenClaw path remains available for normal low-thinking turns when cancellation polling is not required.

## Removed

- The 7.3 installer hero animation.
- The 7.3 horizontal numbered subsystem rail.
- The Desktop/Server deployment dropdown as the primary mode selector.
- Silent skipping of matched privileged skills that explicitly provide a safe matcher.

## Fixed

- Server mode is visible immediately on the deployment screen.
- Installer layout no longer depends on fixed-width animated box art during live SSH/terminal resizing.
- Sidebar body indentation and interactive prompts stay aligned after the Control Deck switches into wide layout.
- Agent cancellation no longer stops only a wrapper process on platforms where OpenClaw may have child processes.
- Condition watches do not announce until their local predicate actually evaluates true.
- Expired proactive items and expired condition watches are retired instead of being delivered late.
- A matched privileged skill can explain the required permission without running its handler.

## Compatibility

- Jervis config schema advances to 3 and migrates 7.3 config with continuity, presence-return, and proactive defaults.
- Jervis state schema advances to 3 and preserves existing 7.3 users, memories, dialogue, notifications, and agent history while adding 7.4 metadata/tables.
- Database/config migration remains protected by the 7.3 snapshot-before-migration recovery layer.
- Official native targets remain Linux x64/ARM64, Windows x64, macOS Intel, and macOS Apple Silicon.
- OpenClaw remains the authoritative source for provider/API/plugin onboarding.
- Action/tool timeline entries are shown only when OpenClaw returns usable action metadata; Jervis does not fabricate tool history.
- Guaranteed cancellation applies to the long-running CLI-backed agent path. Low-thinking HTTP calls remain optimized for latency and are not advertised as synchronously cancellable.
