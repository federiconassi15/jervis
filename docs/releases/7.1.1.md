# Jervis 7.1.1

7.1.1 turned the initial public scaffold into a substantially more complete cross-platform product and release pipeline.

## Added

- Self-contained PyInstaller native binaries for Windows x64, Linux x64/ARM64, macOS Intel, and macOS Apple Silicon.
- Native binary build/verification scripts: `build_native.py`, `native_entry.py`, and `verify_native.py`.
- A dedicated install engine and install plan.
- Native-build smoke jobs across all supported operating systems and architectures.
- A richer mouse-capable terminal installer and installer UI tests.
- Cross-platform release artifact assembly and checksums.

## Changed

- Expanded the release workflow from one build job into metadata, source, native, and publish stages.
- Reworked bootstrap/install behavior around native release assets while retaining the Python source/bootstrap path.
- Reworked OpenClaw setup and authentication flow.
- Reworked Linux prerequisite and ADB discovery/install handling.
- Expanded README, installer specification, and changelog documentation.

## Removed

- Large parts of the earlier minimal installer implementation were replaced by the install-engine/plan architecture.
- Several duplicated prerequisite/OpenClaw setup paths were consolidated.

## Fixed

- Cross-platform startup and service handling.
- OpenClaw detection after installation.
- Android ADB discovery and audio timeout handling.
- Selected-output TTS and Jervis volume behavior.
- Installer rollback/fresh-machine prerequisite handling.
- Repeated speaker-authentication behavior in normal conversations.
