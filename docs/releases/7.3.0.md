# Jervis 7.3.0

7.3 is a runtime-speed rebuild. The installer is not the focus; the voice loop, state engine, OpenClaw path, audio hot path, and identity path are.

## Added

- Optional Rust/PyO3 acceleration module under `native/jervis_fast`.
- Native single-pass RMS, clipping, audio-quality, and adaptive-VAD routines with a NumPy fallback.
- A fast OpenClaw Gateway HTTP transport using the official local `/v1/responses` surface when available, with CLI fallback.
- Configurable Gateway fast-path URL/retry controls.
- Background prewarming for Whisper STT, speaker recognition, wake detection, and common TTS phrases.
- Batched per-user context snapshots for brain routing.
- Transport telemetry so Jervis records whether a turn used Gateway HTTP or CLI.
- Regression tests for accelerated audio, Gateway response parsing/transport, and batched state snapshots.

## Changed

- Version advanced from 7.1.1 to 7.3.0.
- SQLite now uses WAL + `synchronous=NORMAL`, memory temp storage, busy timeout, periodic pruning, and an embedding cache.
- Dialogue/event retention housekeeping moved off the per-turn hot path.
- Presence updates now combine presence + last-seen work in one transaction.
- Whisper defaults to a low-latency beam-1 profile, disables redundant Whisper VAD after Jervis capture VAD, and stays warm longer.
- OpenClaw CLI discovery is cached instead of rediscovered for every request.
- Low-thinking OpenClaw turns prefer Gateway HTTP; deep/high-thinking turns retain the CLI path so explicit thinking controls are preserved.
- Speaker matching is vectorized into per-user NumPy matrices instead of repeated per-embedding normalization/dot-product calls.
- Desktop audio buffering uses a condition/deque instead of `queue.Queue`.
- Android resampling axes are cached instead of regenerated for every audio frame.
- Runtime activity writes and volume reads are cached/deduplicated.
- Barge-in computes playback leakage baseline once instead of sorting it continuously.

## Removed

- Repeated OpenClaw CLI path discovery from the normal request path.
- Repeated SQLite pruning scans on every dialogue/event insertion.
- Repeated speaker-embedding JSON decoding and per-embedding cosine setup on every identity match.
- Python `queue.Queue` overhead from the desktop microphone callback path.
- Redundant Whisper VAD on audio that Jervis has already captured with its own VAD.
- Repeated barge-in baseline sorting while speech is playing.

## Fixed

- Small-retention database configurations still prune immediately while production-sized stores use batched pruning.
- Fast-path telemetry remains compatible with test/dummy brain implementations.
- The inherited compact-terminal installer nav no longer overflows a 30-row test terminal.

## Compatibility

- Rust acceleration is optional. If the extension is unavailable, Jervis falls back to NumPy/Python behavior.
- The Gateway HTTP fast path is opportunistic. If the endpoint is disabled, unreachable, or requires unavailable auth, Jervis falls back to `openclaw agent`.
- Deep/high-thinking turns continue to use the CLI so Jervis does not silently drop explicit OpenClaw thinking controls.
